3. Functional Requirements

Navigation
* FR-017 The system shall provide a navigation menu on all public pages.
* FR-018 The system shall display all available navigation items in the navigation menu.
* FR-019 The system shall navigate to the selected page when a navigation menu item is selected.

Language Selection
* FR-020 The system shall provide a language selection control.
* FR-021 The system shall display the available languages.
* FR-022 The system shall allow the user to select a language.
* FR-023 The system shall update the user interface to the selected language.
* FR-024 The system shall preserve the selected language during navigation.

Notifications
* FR-025 The system shall display active notifications on the Home Page.
* FR-027 The system shall allow the user to open the notifications drop-down list.
* FR-028 The system shall display the notifications content in the drop-down list.
* FR-029 The system shall allow the user to close the notifications drop-down list.

News
* FR-030 The system shall display news items on the Home Page.
* FR-031 The system shall display the news image, publication date and title for each news item.
* FR-032 The system shall allow the user to open a selected news item.
* FR-033 The system shall display the full content of the selected news item.
* FR-034 The system shall allow the user to navigate to the next set of news items.
* FR-035 The system shall allow the user to navigate to the previous set of news items.
* FR-036 The system shall allow the user to search for news items using keywords.

Changes
* FR-037 The system shall display available routes with current changes information.
* FR-038 The system shall allow the user to select a specific route to view related changes.
* FR-039 The system shall display changes associated with the selected route.
* FR-041 The system shall allow the user to switch between available routes and view related changes.
* FR-042 The system shall visually associate the selected route with the corresponding route on the map.

Map
* FR-043 The system shall display the interactive map.
* FR-044 The system shall allow the user to zoom in and zoom out on the map.
* FR-045 The system shall allow the user to move the map view.
* FR-046 The system shall provide map language selection options.
* FR-047 The system shall display available train routes on the map.
* FR-048 The system shall visually distinguish different train routes using route indicators.
* FR-049 The system shall display moving train indicators on active routes.
* FR-050 The system shall allow the user to select a train indicator to view train information.
* FR-051 The system shall display train details including train number, route, delay status, next stop, departure time, and arrival time.
* FR-052 The system shall allow the user to select different train indicators and view corresponding train information.
* FR-053 The system shall allow the user to select a station on the map.
* FR-054 The system shall display the selected station name and available station options.
* FR-055 The system shall provide access to nearby train information for the selected station.
* FR-056 The system shall allow the user to search for a station using the station search function.
* FR-057 The system shall display upcoming trains for the selected station.
* FR-058 The system shall display train departure and arrival information for the selected station.
* FR-059 The system shall allow the user to search for train information by train route or direction.
* FR-060 The system shall display the selected train route and current train position on the map.

### Ticket Purchase Flow

   Train Search
* FR-001 The system shall allow the user to select a departure station.
* FR-002 The system shall allow the user to select a destination station.
* FR-003 The system shall allow the user to select a travel date.
* FR-004 The system shall display available train routes matching the search criteria.
* FR-005 The system shall display a validation message when required fields are not completed.
* FR-006 The system shall allow the user to sort the search results.
* FR-007 The system shall display the search results according to the selected sorting option.
* FR-008 The system shall allow the user to view detailed information for each train from the search results.

  Ticket Selection
* FR-009 The system shall navigate to the Ticket Selection page when the ticket cart icon is selected.
* FR-010 The system shall display the available ticket types.
* FR-011 The system shall allow the user to select an available ticket type.
* FR-012 The system shall display ticket options for the selected ticket type.

  Ticket Purchase
* FR-013 The system shall allow the user to purchase a ticket as a guest or as a registered user.
* FR-014 The system shall provide the option to register before completing the ticket purchase.
* FR-015 The system shall display the available payment methods.
* FR-016 The system shall allow the user to select a payment method.
